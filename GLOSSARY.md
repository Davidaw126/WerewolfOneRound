# Werewolf Judge Helper

A phone-in-hand helper for a face-to-face 狼人杀 table: one phone per player, plus the host's phone running the night and narrating.

## People

**Room (房间)**:
One table's space in the app, joined with a 6-digit room code. It lasts from when the Host creates it until the Host leaves or it expires, and can hold several games in a row.
_Avoid_: Lobby (the page you pick a room from), session, table

**Host (房主)**:
The one person who runs a room: sets up roles, starts and stops the game, and sees every secret while it runs. A room has exactly one host at a time.
_Avoid_: Judge, admin, owner, 法官 (when meaning the person, not the narration voice)

**Hand over host (转让房主)**:
The host making another person in the room the new host. Only possible before a game starts.
_Avoid_: Transfer ownership, promote

## Going missing

**Leave (离开)**:
A player deliberately quitting the room with the leave button. Leaving mid-game ends that game for the whole table.
_Avoid_: Quit, exit

**Drop (掉线)**:
A player's phone losing its connection without them choosing to (screen locked, app switched, battery dead). A drop never costs the player their seat; coming back on the same phone restores them.
_Avoid_: Disconnect (in UI text), timeout, AFK

**Kick (踢出)**:
The host removing a player from their seat. Only possible before a game starts. Not a ban: a kicked player can rejoin.
_Avoid_: Remove, ban

## Dealing

**Re-deal (重新发牌)**:
Shuffling every role out to the seats again before the game starts, so any role a player has already seen no longer counts.
_Avoid_: Reroll, reshuffle
